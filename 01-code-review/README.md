# Module 1 - Code Review

**File:** [`EmployeeForm.review.tsx`](EmployeeForm.review.tsx) - a standalone copy of the
real `employee-management-system/src/components/EmployeeForm.tsx`
(imports are illustrative; this fileit isn't wired into the build).

## Objective

Practice using an AI assistant to perform a **thorough, prioritized** code review -
not a blind **"fix everything"** pass.

## Task

1. Ask an AI assistant to review `EmployeeForm.review.tsx` for security, accessibility,
   correctness, and maintainability issues.

2. Use the assistant to produce a **prioritized**
   list (critical / moderate / minor) rather than an unordered dump.

3. Pick the top 3 issues yourself and explain, in your own words, why they matter.

## Deliverable

- The prompt(s) you used (including any follow-ups asking it to prioritize or justify).
- The assistant's review output.
- Your own top-3 picks and why.
